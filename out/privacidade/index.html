Política de Privacidade

Última atualização: Abril de 2026

1. Introdução

A ISA — Intelligent Systems for Accounting (“ISA”, “nós”) opera a plataforma Isa Concilia. Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos seus dados pessoais em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

2. Dados que Coletamos

Podemos coletar os seguintes dados pessoais:

  • Dados de identificação: nome completo, CPF/CNPJ, e-mail, telefone
  • Dados profissionais: nome do escritório, cargo, número de registro profissional
  • Dados de uso: informações sobre como você utiliza a plataforma, incluindo logs de acesso, funcionalidades utilizadas e preferências
  • Dados financeiros: extratos bancários e dados contábeis fornecidos pelo usuário para fins de conciliação (processados e não armazenados permanentemente sem consentimento)

3. Finalidade do Tratamento

Utilizamos seus dados pessoais para:

  • Fornecer e manter os serviços da plataforma Isa Concilia
  • Processar conciliações bancárias automatizadas
  • Melhorar e personalizar a experiência do usuário
  • Enviar comunicações sobre o serviço e atualizações relevantes
  • Cumprir obrigações legais e regulatórias

4. Base Legal

O tratamento de dados pessoais é realizado com base nas seguintes hipóteses legais previstas na LGPD:

  • Consentimento do titular (Art. 7º, I)
  • Execução de contrato (Art. 7º, V)
  • Exercício regular de direitos (Art. 7º, VI)
  • Legítimo interesse do controlador (Art. 7º, IX)

5. Compartilhamento de Dados

Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros para fins comerciais. Podemos compartilhar dados com:

  • Prestadores de serviços essenciais para o funcionamento da plataforma (hospedagem, infraestrutura)
  • Autoridades públicas, quando exigido por lei ou ordem judicial

Todos os prestadores de serviços são obrigados a manter a confidencialidade dos dados.

6. Segurança dos Dados

Adotamos medidas técnicas e organizacionais para proteger seus dados pessoais:

  • Criptografia de dados em trânsito e em repouso
  • Controle de acesso baseado em funções
  • Monitoramento contínuo de segurança
  • Servidores localizados no território brasileiro

7. Seus Direitos

Nos termos da LGPD, você tem direito a:

  • Confirmação da existência de tratamento de dados
  • Acesso aos seus dados pessoais
  • Correção de dados incompletos ou desatualizados
  • Anonimização, bloqueio ou eliminação de dados desnecessários
  • Portabilidade dos dados
  • Informação sobre compartilhamento de dados
  • Revogação do consentimento

Para exercer seus direitos, entre em contato conosco.

8. Retenção de Dados

Mantemos seus dados pessoais apenas pelo período necessário para cumprir as finalidades descritas nesta política, ou conforme exigido por lei.

9. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. Notificaremos sobre alterações significativas através da plataforma ou por e-mail.
