Política de Privacidade

Última atualização: Abril de 2026

A ISA Concilia respeita a sua privacidade e está comprometida com a proteção dos dados pessoais de acordo com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

1. Dados Coletados

Podemos coletar:

  • Nome e e-mail (quando fornecidos voluntariamente)
  • Dados de uso do site (cookies, analytics)

2. Finalidade

Utilizamos os dados para:

  • Fornecer e melhorar nossos serviços
  • Responder solicitações
  • Análise de uso

3. Base Legal

Tratamos dados com base em:

  • Consentimento
  • Legítimo interesse

4. Compartilhamento

Não vendemos dados pessoais. Podemos compartilhar com provedores técnicos necessários.

5. Retenção

Dados são mantidos apenas pelo tempo necessário para cumprir as finalidades.

6. Direitos do Titular

Você pode:

  • Acessar seus dados
  • Corrigir dados
  • Solicitar exclusão
  • Revogar consentimento

7. Segurança

Adotamos medidas técnicas e organizacionais para proteger os dados.

8. Contato

Para exercer seus direitos: contato@isaconcilia.com
